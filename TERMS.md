# Terms of Use for the Neo Angband Borg Mod

Effective date: 2026-08-23.

Borg is an optional mod folder for Neo Angband, not a separate game service. It requires a compatible Neo Angband installation. Installing the mod does not create an account, provide a server-side character store, or send a character or gameplay record to a project-operated service.

When enabled, the Borg can observe the game through the host interfaces declared in its manifest and issue game commands as an automatic player. Enabling the mod and handing it the keyboard are separate choices: press Ctrl-Z in play to confirm and hand over control. A character that the Borg controls is permanently marked as autoplayed and is excluded from the high-score table. Borg is not a promise that a character will survive, progress, buy items, or make a particular decision.

The examined shipped mod manifest does not declare network access, and the examined shipped plugin code does not make network requests. Installation from the in-game mod manager can still retrieve this mod's public files from GitHub because that is a function of Neo Angband's mod manager. The core Neo Angband Terms and Privacy Policy describe those shared host behaviors, local storage, update checks, and third-party mod risks.
