# Terms of Use for the Neo Angband Borg Mod

Effective date: 2026-08-23.

Borg is an optional mod folder that runs inside a compatible Neo Angband installation, with no separate hosted service. Installing the mod does not create an account, provide a server-side character store, or send a character or gameplay record to a project-operated service.

When enabled, the Borg plays as an automatic player: it observes the game through the host interfaces declared in its manifest and issues game commands. Enabling the mod does not hand it the keyboard. The player does that by pressing Ctrl-Z during play and confirming, or by starting a character from the New Borg character row on the title screen. A character the Borg controls is permanently marked as autoplayed and excluded from the high-score table. The Borg makes no promise that a character will survive, progress, buy items, or make any particular decision.

Its shipped manifest does not declare network access, and its shipped plugin code makes no network requests. Installing or updating it from the in-game mod manager can still fetch its public files from GitHub; those requests come from the Neo Angband host's mod manager. The core Neo Angband Terms and Privacy Policy cover that shared host behavior, including local storage, update checks, and the risks of optional third-party mods.
