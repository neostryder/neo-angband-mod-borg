# Standalone pilot example

Generated by the standalone CLI against official engine
`d27ed50f9e3b650a43cceda5a0c007d03cc321df` and the upstream-based Borg source at
`5c3e099` (the full source identity is in report.json). Two assigned births
from the frozen seeded-v2 suite, two workers, 2,000 exact ticks, 120-second
watchdogs. Both reached the cap alive. Raw traces and birth/final engine saves
were retained in the configured local output directory during validation; both
Warrior snapshots successfully load through Core.loadGame (turns 0 and 2,000).
This small pilot validates host/report/save plumbing, not a survival estimate.

A separate unadapted Human Mage seed 3010 control capped after-loop at tick 5,002
for a requested 5,000, verifying that historical cap overshoot stays visible.
The watchdog/crash/wrong-birth/wrong-seed and multiworker outcome controls are
synthetic process tests, reported separately from these real games.
